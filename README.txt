First day of the week project
=============================

Notebook: first-day-of-week.ipynb

I used three csvs:

- first-day-of-week.csv
  first weekday for each territory, plus units and paper size
  (unicode CLDR)

- population.csv
  2020 population in millions
  (UN / gapminder)

- four-regions.csv
  africa, americas, asia, europe
  (gapminder)

Stuff I looked at:
- counts by first day
- population by first day
- breakdown by region (countries and people)
- friday/saturday countries
- units + paper size
- missing rows after the merge
- top 15 countries
- a couple charts

Run the notebook from this folder so the csv paths work.
